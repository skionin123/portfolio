CoBest · Product / Full-Stack Build

A website and commerce platform that starts with the business.

CoBest combines guided shop set-up, a storefront editor, products, orders, customers and content in one workspace. I build it hands-on with AI-assisted development, from the React front end to the tests and deployment.

What it covers

Guided onboarding, theme presets, a storefront editor with live preview, product and catalog management, orders, customers, discounts and a blog and content area.

How it’s built

React, Vite, Tailwind CSS and Zustand on the front end, a Node server with Supabase, automated tests in Vitest and Playwright, deployed on Railway.

Try it

The guest demo lets anyone name a shop, add a product and publish a storefront preview without creating an account.
